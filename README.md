# FlipHelper - Free BloxFlip extension for balance tracking, autobet, and more.

The simplest and most reliable BloxFlip extension for all.

## Features:
 - Track live balance session stats: Net Profit, Wagered Amount, and Win/Loss record
 - Intelligent safety guard: Blocks and warns you on accidental all-in bets
 - Advanced auto-betting bot: Set strategies for Mines, Towers, and Dice
 - Martingale presets: Toggle Martingale or Reverse Martingale setups in one click
 - Stop-Loss & Take-Profit: Protect your balance with automatic profit targets and loss thresholds

How to use
 1. Install [FlipHelper BloxFlip extension](https://chromewebstore.google.com/detail/gigdjboogoiicioekhcpdfhkofmjnpgf?authuser=0&hl=en) and visit BloxFlip.
 2. The FlipHelper BloxFlip extension will automatically appear as a floating dashboard.
 3. Configure your desired options, set up the auto-betting bot parameters, and press Alt+A or the extension button in the toolbar to hide/show FlipHelper at anytime.

You can also download the binary, unpack it, then load it to any chromium browser you'd like.

Completely free, no ads, open-source.
